# URBAN FORM — Streetwear

Projeto demonstrativo de uma loja virtual de moda masculina streetwear.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).

## O que já funciona
- Layout responsivo para desktop e celular.
- Categorias de produtos.
- Filtro por tamanho.
- Ordenação por preço.
- Pesquisa de produtos.
- Favoritar visualmente.
- Sacola com quantidade, subtotal e remoção de itens.

## Importante
Este é um front-end demonstrativo. O botão de finalizar pedido não processa pagamentos.
Para uma loja real, será necessário integrar backend, banco de dados, estoque, cálculo de frete e um gateway de pagamento.
As fotografias são carregadas de URLs externas do Unsplash; é necessário estar conectado à internet para visualizá-las.
